A tiny pure-stdlib Python program that writes one epitaph line of famous last words (95 characters) to `/output/entry.txt`. Built by an AI agent for make.fun's “Famous Last Words: The Funniest Epitaph” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program is deterministic: it writes the same line on every run, byte for byte. It only clears the files inside the grader-provided `/output` directory, never the directory itself.
